# 🧮 Calculadora Inteligente

Calculadora em Python com interface gráfica (Tkinter) e tema escuro, desenvolvida para praticar lógica de programação, estruturas de decisão e criação de interfaces.

## ✨ Funcionalidades

- Soma, subtração, multiplicação e divisão
- Interface gráfica com campos de entrada e botões coloridos
- Tratamento de erros (divisão por zero e entradas inválidas)
- Aceita números decimais, com vírgula ou ponto
- Botões de limpar e sair

## 🛠️ Tecnologias

- Python 3.10+
- Tkinter

## 💡 Conceitos praticados

- Estrutura `match/case` (pattern matching)
- Funções e eventos de botões
- Tratamento de exceções com `try/except`
- Desenvolvimento de interfaces gráficas

## ▶️ Como executar

```bash
python calculadora_tkinter.py
```

> O Tkinter já vem instalado com o Python, então não é preciso instalar nada.
